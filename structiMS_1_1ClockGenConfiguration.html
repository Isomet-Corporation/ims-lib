Detailed Description

Set values in this struct to configure the clock generator for clock output mode.

Modify the values present in this struct and pass the struct by reference to the SystemFunc::ConfigureClockGenerator() function to update the clock generator configuration

e.g.

SystemFunc sys(myiMS);
ClockGenConfiguration cfg;
cfg.ClockFreq = kHz(700.0);
cfg.AlwaysOn = true;
sys.ConfigureClockGenerator(cfg);
