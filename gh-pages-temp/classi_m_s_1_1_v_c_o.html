◆ VCO()

iMS::VCO::VCO ( std::shared_ptr< IMSSystem > ims)

Constructor for VCO Object.

An IMSSystem object, representing the configuration of an iMS target must be passed by const reference to the VCO constructor.

The IMSSystem object must exist before the VCO object, and must remain valid (not destroyed) until the VCO object itself is destroyed.

Once constructed, the object can neither be copied or assigned to another instance.

Parameters
[in]imsA const reference to the iMS System
