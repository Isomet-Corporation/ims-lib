enum iMS::FirmwareUpgradeEvents::Events

List of Events raised by the FirmwareUpgrade module.

Enumerator
FIRMWARE_UPGRADE_DONE 

Triggered when the upgrade process completes.

FIRMWARE_UPGRADE_ERROR 

Triggered if there is an error in the upgrade process.

FIRMWARE_UPGRADE_STARTED 

Triggered immediately after the upgrade has started.

FIRMWARE_UPGRADE_INITIALIZE_OK 

Triggered when the upgrade process has completed initialising.

FIRMWARE_UPGRADE_CHECKID_OK 

Triggered when the upgrade process has successfully identified the Flash ID Code.

FIRMWARE_UPGRADE_ENTER_UG_MODE 

Triggered on Starting the Upgrade Process (any subsequent failure would result in the device booting from its golden image).

FIRMWARE_UPGRADE_ERASE_OK 

Triggered when the Flash program area has been erased.

FIRMWARE_UPGRADE_PROGRAM_OK 

Triggered when the Flash has completed downloading the new firmware image.

FIRMWARE_UPGRADE_VERIFY_OK 

Triggered when the Flash has verified the CRC of the downloaded image.

FIRMWARE_UPGRADE_LEAVE_UG_MODE 

Triggered on completing the upgrade process (the device will now boot from the freshly downloaded image).
