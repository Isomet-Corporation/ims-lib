Detailed Description

Class for performing Compensation related functions with the Synthesiser.

The purpose of this class is to perform compensation tasks such as measuring the diffraction efficiency of an AO device across a range of frequencies. Such data can then be used to build Compensation tables.

A CompensationFunction object defines a set of parameters for each feature of compensation (amplitude, phase, sync digital and sync analog) at given spot frequency points. It also defines the style of interpolation to use when rendering a CompensationTable from the CompensationFunction object.

It is not used for storing Compensation Table data or for downloading Compensation Tables. See the CompensationTable and CompensationTableDownload classes for these requirements.

enum class iMS::CompensationFunction::InterpolationStyle
strong

Selects the style with which the point specifications in a function are applied when generating a CompensationTable.

Enumerator
SPOT 

Spot frequency style is used when the point specification is desired at only one frequency entry in the table.

STEP 

Stepped frequency style is used when the point specification is to apply at or above this frequency until the next entry becomes valid.

LINEAR 

Linear style applies a linear interpolation of the point specifications between two frequencies. Endpoint extrapolation is constant value.

LINEXTEND 

Linear with Extension applies a linear interpolation with linear extrapolation at the end points.

BSPLINE 

Cubic B-Spline interpolation applies a curve fit between all point specifications throughout the function.
