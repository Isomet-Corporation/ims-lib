Detailed Description

The entire API is encapsulated by the iMS namespace.

In User application code, either add the line 'using namespace iMS;' at the start of your application, or prefix all classes, functions etc with 'iMS::'

Enumeration Type Documentation

◆ CompensationFeature

enum class iMS::CompensationFeature
strong

The Four features that are present in the compensation table.

Enumerator
AMPLITUDE 

Amplitude compensation is used to correct for frequency-dependent amplitude non-linearities.

PHASE 

Phase compensation is used to correct for frequency-dependent phase effects.

SYNC_DIG 

Synchronous Digital compensation may be used to assert digital I/O synchronously with programmed frequency ranges.

SYNC_ANLG 

Synchronous Analog compensation may be used to provide an analog control signal that is a function of RF Frequency.

◆ CompensationModifier

enum class iMS::CompensationModifier
strong

Used when generating a CompensationTable from a CompensationFunction to indicate whether the new data should overwrite the old data, or update it.

Enumerator
REPLACE 

Newly generated CompensationTable data overwrites the previous set of data in the CompensationTable.

MULTIPLY 

Newly generated CompensationTable data is multiplied by the existing data and updated in the CompensationTable.

◆ DAC_CURRENT_REFERENCE

enum class iMS::DAC_CURRENT_REFERENCE
strong

Sets the amount by which the current reference controlling the DAC amplitude is scaled down by in enhanced tone modes.

Note that normal amplitude control is not possible with linear sweeps, so the DAC current reference is provided as an alternative.

Since
1.4.3
Enumerator
FULL_SCALE 

(Default) Output signal uses full current reference

HALF_SCALE 

Output signal reduced to half of current reference.

QUARTER_SCALE 

Output signal reduced to 1/4 of current reference.

EIGHTH_SCALE 

Output signal reduced to 1/8 of current reference.

◆ SequenceTermAction

enum class iMS::SequenceTermAction : std::uint8_t
strong

Operation to perform on the completion of the last repeat of the last entry in a Sequence.

Since
1.2.4
Enumerator
DISCARD 

Delete the ImageSequence from the Sequence Queue and move on to the next Sequence, if it exists, otherwise Stop.

RECYCLE 

Move the ImageSequence to the end of Sequence Queue and move on to the next Sequence, if it exists, otherwise repeat this ImageSequence.

STOP_DISCARD 

Delete the ImageSequence from the Sequence Queue and stop playback.

STOP_RECYCLE 

Move the ImageSequence to the end of Sequence Queue and stop playback.

REPEAT 

No effect on the Sequence Queue. Repeat the current Sequence.

REPEAT_FROM 

No effect on the Sequence Queue. Repeat the current Sequence starting from the ImageSequenceEntry index specified in the Termination Value.

INSERT 

Move the ImageSequence to a location in the Sequence Queue, inserting it before another sequence.

STOP_INSERT 

Move the ImageSequence to a location in the Sequence Queue and stop playback.
